# Bedrock Beacon brand

## Position

Bedrock Beacon is the local command center for multiple Minecraft Bedrock worlds. The core idea is **one signal, every world**: a single private control point that makes independent servers visible, understandable, and easy to operate.

## Voice

- Clear, capable, and reassuring.
- Prefer short operational language: “Start world”, “Beacon is restarting”, “Server is ready”.
- Emphasize local control, visibility, and reliability.
- Avoid nautical language inherited from the former Harbor name.

## Visual identity

- Primary mark: the `BB` monogram in a dark rounded block.
- Hero motif: a luminous block-built beacon connecting several floating worlds.
- Deep green `#101611`: foundations, navigation, and high-contrast surfaces.
- Beacon green `#247A48`: actions and active navigation.
- Signal lime `#DFF35C`: highlights, status accents, and beacon light.
- Warm cloud `#F4F5EF`: application background.
- Typography: Space Grotesk for headings and DM Sans for interface copy.

## Login message

**One signal. Every world.**

Run and discover every Bedrock world from one private control point.
