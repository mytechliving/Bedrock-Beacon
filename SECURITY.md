# Security policy

## Supported versions

Security fixes are applied to the latest published Bedrock Beacon release.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository owner privately through the contact method listed on their GitHub profile.

Include reproduction steps, affected versions, impact, and suggested mitigations. Do not include real credentials, private keys, player identifiers, or world data.

## Sensitive local files

The following paths may contain private or licensed material and are intentionally excluded from Git:

- `data/`
- `Servers/`
- `runtime/`
- `dist/`
- `node_modules/`
- `bedrock-server-*.zip`
- `service/*.exe`
